# Практическая работа № 4 — Climate Control, вариант 3

Автор: Хусаинов Арсен Ильдарович.

Работа посвящена измерению метрик кода проверки показаний IoT-датчиков. Сравниваются исходная версия метода с вложенными условиями и версия после рефакторинга. В отчёте есть таблицы метрик, скриншоты Visual Studio, результаты семи проверок и полный листинг.

## Файлы репозитория

- `ПР4_Хусаинов_Арсен_Ильдарович.docx` — готовый отчёт Word.
- `ПР4_Вариант3_ClimateControl_проект.zip` — архив исходного проекта Visual Studio.

## Как открыть отчёт

1. На странице репозитория нажмите имя файла `ПР4_Хусаинов_Арсен_Ильдарович.docx`.
2. Нажмите кнопку **Download raw file** или **Raw**, чтобы скачать документ.
3. Откройте скачанный файл в Microsoft Word. Ссылка на этот репозиторий находится во введении отчёта.

## Как открыть проект

1. На странице репозитория нажмите `ПР4_Вариант3_ClimateControl_проект.zip`, затем **Download raw file**.
2. Распакуйте ZIP в отдельную папку.
3. Откройте в Visual Studio файл `ClimateControlMetrics/ClimateControlMetrics.csproj`.
4. Нажмите **Сборка → Собрать решение**, затем **Отладка → Запуск без отладки** (Ctrl+F5).
5. В консоли должны пройти 7 проверок; итоговая строка: `Итог: 7/7; расхождений: 0`.

Для запуска из терминала перейдите в `ClimateControlMetrics` и выполните `dotnet run`. Требуется установленный .NET 10 SDK.
